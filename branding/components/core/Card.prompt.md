Surface container for content blocks — machine cards, services, testimonials.

```jsx
<Card accentEdge interactive padding="var(--space-6)">
  <h3>Mitsui Seiki</h3>
  <p>High precision 4 &amp; 5 axis machining centers.</p>
</Card>
```

`accentEdge` adds the signature yellow top keyline; `interactive` enables hover lift. Default padding is `--space-5`.
